# Banking Operations Application

A Java-based banking application designed to demonstrate basic banking operations through a graphical user interface (GUI). The application uses File I/O to store and retrieve information, providing a simple way to manage banking-related records.

## Features
- Graphical User Interface (GUI)
- File handling for data storage and retrieval
- Banking operation management
- Structured application workflow

## Technologies Used
- Java
- Java GUI
- File I/O

## Concepts Demonstrated
- Object-Oriented Programming (OOP)
- File Handling
- GUI Development
- Application Logic

## Purpose
This project was developed to strengthen Java programming skills and understand how desktop applications manage user interactions and persistent data.
